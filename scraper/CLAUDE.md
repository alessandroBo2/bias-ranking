# CLAUDE.md — Instructions for Claude Code

## Project context

This is the code for a Bachelor's thesis in Data Science. The goal is to analyze
**algorithmic bias in Google Shopping results** by comparing prices and sellers
across three language markets (IT / EN / DE) using a stratified dataset of queries.

The student already has an Apify account (actor `burbn/google-shopping-scraper`) and an
Anthropic account. The keys must be placed in the `.env` file before any run.

## Initial setup (do it once)

### 1. Check Python ≥ 3.10

```bash
python --version
# On Windows you may need: py --version
```

### 2. Install the dependencies

```bash
pip install -r requirements.txt
```

If `pip` doesn't work: `pip3 install -r requirements.txt` or
`python -m pip install -r requirements.txt`.

### 3. Configure the API keys

```bash
# Copy the template
cp .env.template .env   # Linux/Mac
copy .env.template .env  # Windows
```

Open `.env` with a text editor and enter:

```
APIFY_TOKEN=apify_api_xxxxxxxxxxxxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxx
```

- **APIFY_TOKEN**: from https://console.apify.com → Settings → Integrations → API token
- **ANTHROPIC_API_KEY**: from https://console.anthropic.com → API Keys

### 4. Verify the configuration

```bash
python -c "
from dotenv import load_dotenv; import os; load_dotenv()
at = os.environ.get('APIFY_TOKEN','')
ak = os.environ.get('ANTHROPIC_API_KEY','')
print('APIFY_TOKEN:', 'OK' if at.startswith('apify_api_') else 'MISSING')
print('ANTHROPIC_API_KEY:', 'OK' if ak.startswith('sk-ant-') else 'MISSING')
"
```

## Database behavior

- `results.db` is **append-only**: each run adds data without overwriting.
- **Same Apify run re-executed** → new `run_id` → new rows (price snapshot).
- **Same run imported twice** → rows ignored (`INSERT OR IGNORE` on `run_id, position`).
- **To start over from scratch**: delete `results.db` and the `raw/` folder.

---

## Implemented bias metrics

1. **Seller concentration** — HHI (Herfindahl-Hirschman Index), Gini, CR-3/CR-5
2. **Position bias** — position × average price correlation; who occupies the top 3?
3. **Cross-language disparity** — same `query_id` in IT/EN/DE: price delta %
4. **Price clustering** — CoV (Coefficient of Variation) for the price filter bubble
5. **Category coverage** — does Google return balanced results across categories?

## Important technical notes

- **`--max-results 20` is the absolute minimum** imposed by the Apify `burbn` actor.
  You cannot request fewer. To save credits: reduce the number of
  queries, not the results per query.
- **`--max-results` is a cap, not a target**: Google may return fewer products
  if the keyword is poorly indexed for that market. The pipeline prints a warning.
- **Rating and reviews** can be NULL: Google doesn't always expose them.
  All charts filter the nulls automatically.
- **Encoding on Windows**: if you see character errors, first run
  `$env:PYTHONIOENCODING="utf-8"` in PowerShell.

## Troubleshooting

| Error | Cause | Solution |
|---|---|---|
| `ModuleNotFoundError` | Dependencies not installed | `pip install -r requirements.txt` |
| `APIFY_TOKEN missing` | `.env` not configured | See Setup §3 |
| `Apify 401 Unauthorized` | Wrong or expired token | Regenerate the token on console.apify.com |
| `input.limit must be >= 20` | You passed `--max-results < 20` | Use at least 20 |
| `database is locked` | Another process is using results.db | Close other terminals |
| `TypeError: float object...` | Empty CSV cell read as NaN | Normal, the code handles it |
| `0 products saved` | Apify returned 0 results | Check the token; retry |
| Dashboard doesn't open | Browser not found | Open `output/dashboard.html` manually |

## How to help the student (instructions for Claude Code)

1. **Before any Apify run**, check that `.env` is configured and show
   the estimated cost for the number of queries they want to run.

2. **Never suggest `--max-results` below 20**: the actor rejects it.

3. **The correct dataset for the thesis is `queries_400_stratified.csv`**, not the pilot.
   The pilot is only for the initial tests.

4. **If the student asks to analyze the data**, always run
   `python main.py explore` first to show how much data is in the DB.

5. **If the student wants to start over from scratch**, ask for explicit confirmation
   before suggesting to delete `results.db`.

6. **For encoding issues on Windows**: always add
   `$env:PYTHONIOENCODING="utf-8"` before the PowerShell commands.
